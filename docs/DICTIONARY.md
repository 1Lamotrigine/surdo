# Инструкция редактору словаря (G5)

Как пополнять словарь жестов: записать жест с камеры, отправить его на проверку,
утвердить или отклонить, разобрать очередь нераспознанных слов. Инструкция для
ролей `editor` и `expert` (носителя). Основа — процесс из ТЗ (раздел 9),
реализация — блоки B и D.

> Публичный список проверенных жестов (`GET /api/dictionary/`) видят все. Черновики,
> запись клипов и очередь слов — только роли словаря. Назначает их администратор в
> Django Admin (`/admin/`), не форма регистрации.

## Роли и что им можно

| Роль | Запись жеста | Отправка на проверку | Утверждение/отклонение | Очередь слов |
| --- | --- | --- | --- | --- |
| `editor` (редактор) | да | да | нет | да |
| `expert` (эксперт-носитель) | да | да | да | да |
| `admin` | да | да | да | да |
| `teacher` | нет | нет | нет | нет |

Статусы жеста: `draft` (черновик) → `review` (на проверке) →
`verified` (проверен) или `rejected` (отклонён). Переходы разрешены только по
таблице `dictionary/statuses.py`; запрещённый переход отклоняется с ошибкой.
Статус «проверен» ставит только эксперт-носитель: смысл, скорость, положение,
мимику проверяет он.

## Куда заходить

| Страница | Адрес | Кому |
| --- | --- | --- |
| Запись жеста с камеры | `/dictionary/record/` | editor, expert, admin |
| Очередь нераспознанных слов | `/dictionary/queue/` | editor, expert, admin |
| Очередь жестов на проверке | `/dictionary/review/` | expert, admin |
| Карточка проверки жеста | `/dictionary/review/<id>/` | expert, admin |
| Django Admin (словарь целиком) | `/admin/dictionary/` | staff |

Вход — по email и паролю: `/accounts/login/`.

## Шаг 1. Записать жест с камеры

1. Откройте `/dictionary/record/`. Камера работает только на `localhost` или по
   HTTPS — браузер иначе её не отдаёт.
2. Нажмите «Включить камеру». При первом запуске браузер скачает WASM MediaPipe
   (~13 МБ) и модель Holistic, дальше они берутся из кэша. Встаньте так, чтобы в
   кадр попали лицо, корпус и обе кисти.
3. Проверьте предпросмотр: поверх видео рисуется скелет (поза, кисти, лицо).
   Поднимите руку и пошевелите пальцами, наклоните голову — линии должны идти
   без заметной задержки. Видео на сервер не отправляется.
4. Нажмите «Начать запись», покажите жест, нажмите «Остановить запись».
   Максимальная длина ограничена настройкой `CLIP_MAX_FRAMES` (по умолчанию 300
   кадров при 30 FPS). Запишите 2–3 дубля и выберите лучший — качество важнее
   количества.
5. Края записи обрезаются автоматически по появлению позы и кистей. При
   необходимости поправьте ползунки «Начало» и «Конец»: клип пересобирается
   сразу, сглаживается фильтром One Euro и проверяется обратной распаковкой.
6. Проиграйте клип на аватаре кнопками «Играть» и «Стоп». Если поза или мимика
   выглядят неправильно — вернитесь к ползункам или запишите заново.
   Предпросмотр работает только при заданном `AVATAR_MODEL_URL`; без модели клип
   всё равно можно сохранить.

## Шаг 2. Сохранить черновик

Заполните поля формы «Метаданные жеста» и нажмите «Сохранить черновик»:

- **Глосса** — слово заглавными буквами, как в словаре, например `УЧЕБНИК`
  (до 100 символов).
- **Язык** — `rsl` (РЖЯ) или `ksl` (КСК).
- **Описание** — контекст, диалект, комментарий для эксперта.

Жест создаётся со статусом `draft` и **студентам ещё не показывается**. После
успеха страница предложит ссылку в Django Admin; там черновик виден в
`/admin/dictionary/sign/`. Файл клипа можно скачать кнопкой «Скачать клип
(.json.gz)» — формат описан в `docs/spec/clip-format.md`.

## Шаг 3. Отправить на проверку (editor)

Из очереди проверок черновиков нет — на проверку жест отправляют из Django Admin
или через сервис `dictionary/services.submit_for_review`. После перехода в
`review` жест попадает в очередь эксперта `/dictionary/review/`.

Через API то же самое делает редактор или эксперт:

```
POST /api/signs/<id>/review/      # {decision, comment} — решение эксперта
```

Создание жеста без веб-страницы (например, из скрипта) — `POST /api/signs/`
(`multipart/form-data` с полем `clip` или JSON без клипа):
только роли словаря, иначе 401/403.

## Шаг 4. Проверить жест (expert)

1. Откройте `/dictionary/review/` — список жестов в статусе «на проверке».
2. Откройте карточку жеста: видны глосса, язык, описание, кто записал, метрики
   клипа и ссылка «Открыть файл клипа».
3. Проверьте смысл, скорость, положение рук, мимику. Если у жеста нет клипа,
   карточка предупредит — запросите клип у редактора.
4. Напишите комментарий для редактора и нажмите:
   - **Утвердить** — жест получает статус `verified`, попадает в публичный словарь
     и **растит версию словаря** (`DictionaryVersion`). Только утверждённые жесты
     видны студентам и используются в глоссах.
   - **Отклонить** — статус `rejected`, версия не меняется, редактор увидит
     комментарий и сможет доработать.

Версия словаря участвует в версии кэша PWA: после утверждения новый жест
скачивается студенту без ручной очистки кэша.

## Шаг 5. Разобрать очередь нераспознанных слов

Слова из реальных занятий, для которых ещё нет жеста, попадают в
`/dictionary/queue/` автоматически (сервис конвейера). Сверху самые частые.

1. Слово в статусе **«Новое»** → «Взять в работу» (статус `queued`).
2. У слова «В работе» → «Записать жест»: ссылка
   `/dictionary/record/?word=<id>` подставит лемму и язык в форму.
3. Запишите и сохраните черновик (шаги 1–2). В одной транзакции со созданием
   жеста слово переходит в статус «Записано» (`recorded`) — повторно его
   записывать не нужно.
4. Дальше жест проходит обычный путь: отправка на проверку (шаг 3) и решение
   эксперта (шаг 4).

Слова в статусах `new` и `recorded` по прямой ссылке возвращают в очередь с
сообщением: записывать можно только слово, взятое в работу.

## Django Admin

Всё перечисленное доступно и в админке (`/admin/dictionary/`):

- **Жесты** — список с клипами, фильтры по статусу и языку, поиск, инлайны
  клипов, предпросмотр файла лучшего клипа.
- **Клипы** — сквозной список всех файлов.
- **Нераспознанные слова** — очередь по убыванию частоты.
- **Версии словаря** — только чтение: версии растут сами при утверждении жестов.

Действия над выделенными жестами: «Отправить на проверку», «Утвердить (эксперт)»,
«Отклонить (эксперт)». Над словами: «Взять в работу», «Пометить записанными».
Запрещённый переход пропускается с предупреждением.

## Ускорение работы

Открытые датасеты жестовых языков (например, Slovo) можно использовать как
справочник и для черновиков клипов. Лицензии проверяйте. Прямая подстановка без
проверки экспертом запрещена.

## Что нужно от людей, а не от системы

Запись и проверку жестов делают редактор и эксперт-носитель, выбор жестового
языка и темы MVP — тоже люди. Без этого проект технически готов, но словарь
пуст: студент видит только дактиль и субтитры (см. `docs/STATE.md`).
