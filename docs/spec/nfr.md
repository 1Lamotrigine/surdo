# Нефункциональные требования, критерии приёмки, безопасность

Источник: `TZ_django.md`, раздел(ы) 4, 11, 17. Копия для этапов генерации.


## 4. Нефункциональные требования

| Параметр | Требование |
| --- | --- |
| Задержка: конец фразы до начала жестов | медиана ≤ 4 с, 95-й перцентиль ≤ 7 с |
| Аватар | 30 FPS на ноутбуке без дискретной видеокарты и на среднем смартфоне |
| Нагрузка | 1 комната, 30 студентов одновременно (MVP), 5 комнат параллельно (цель) |
| Браузеры | Chrome, Edge, Firefox, Safari (последние 2 версии); PWA на Android (Chrome) и iOS (Safari) |
| Данные | Аудио не сохраняется, хранится только текст и глоссы; согласие на обработку; соблюдение закона о персональных данных |
| Доступность | Контраст, размер субтитров, управление с клавиатуры, нет звуковой информации без визуального дубля |
| Деплой | Docker Compose, одна команда на запуск |

## 11. Критерии приёмки MVP

1. Сквозная задержка: медиана ≤ 4 с, 95-й перцентиль ≤ 7 с (замеряется в `utterances`).
2. ≥ 100 проверенных жестов, алфавит дактиля, цифры 0-100.
3. Тестовый набор из 30 типовых фраз темы: ≥ 80% слов покрыты жестами или корректным дактилем.
4. Минимум 3 глухих или слабослышащих тестировщика: опрос понятности (шкала 1-5), цель средняя ≥ 3.5 при субтитрах.
5. Комната на 30 одновременных подключений без деградации.
6. Развёртывание с нуля одной командой за ≤ 15 минут.
7. PWA ставится на Android (Chrome) и iPhone (Safari), микрофон преподавателя работает в браузере на обеих платформах, клипы при повторном заходе берутся из кэша.

## 17. Безопасность и данные

- **Сессии.** Роли определяются сессией Django (cookie `HttpOnly`, `Secure`, `SameSite=Lax`). Студент получает гостевую сессию после ввода имени.
- **CSRF.** POST-запросы из браузера идут с токеном CSRF (заголовок `X-CSRFToken`), включая отправку фраз.
- **WebSocket.** Проверка `Origin` (`AllowedHostsOriginValidator`) и сессии в `connect()`. Сообщения проверяются по роли: писать в чат может любой участник комнаты, отправлять фразы и текст только преподаватель этой комнаты.
- **Ограничение частоты** (значения ориентировочные, в настройках): вход по ID 10 попыток в минуту на IP, чат 5 сообщений за 5 секунд на участника, отправка фраз не чаще одной в секунду.
- **Аудио.** Лимит размера файла (ориентир 2 МБ) и длительности (до 30 с), проверка типа. Файл не пишется на диск и удаляется из памяти после обработки.
- **Персональные данные.** Аудио не хранится. Хранятся имя гостя, текст чата и фраз. Срок хранения задаётся настройкой (ориентир 90 дней), старые записи удаляет команда по cron. Согласие на обработку показывается при входе.
- **Секреты.** Ключ LLM, пароль базы и `SECRET_KEY` только в переменных окружения, `.env` не коммитится.
- **Клипы.** Загружать их может только роль editor, формат клипа валидируется (версия, размеры, число кадров не выше лимита).
- **Продакшен.** `DEBUG=False`, `ALLOWED_HOSTS` и `CSRF_TRUSTED_ORIGINS` с реальным доменом, HTTPS и HSTS.
