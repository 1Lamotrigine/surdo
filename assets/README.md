# Исходные файлы модели и анимаций

Сюда кладутся **исходники** (бинарные файлы не коммитятся). Проект их не читает
напрямую: при подключении файлы попадают в `media/` и в словарь.

```
assets/
├── model/        # модель аватара: *.vrm (обычно один файл avatar.vrm)
├── models/       # *.task: модель MediaPipe Holistic для конвертации Slovo
└── animations/   # жесты: по одному файлу на жест, *.glb или *.vrma
```

## Модель MediaPipe

`assets/models/holistic_landmarker.task` скачивается автоматически при первом
запуске `scripts/slovo_to_clips.py` (13 МБ, официальная float16-модель Google).
В git не попадает. URL можно переопределить переменной окружения
`MEDIAPIPE_HOLISTIC_MODEL_URL` или ключом `--model-url`.

## Модель

Положить сюда `.vrm` (например, `assets/model/avatar.vrm`). Имя любое. Модель
должна быть валидной VRM с humanoid-скелетом; лицензия проверяется отдельно.

## Анимации

- Один жест — одна анимация. Можно по файлу на жест (`uchebnik.glb`) или один
  файл с несколькими записями (`gestures.glb`): тогда имя каждой анимации —
  глосса (`УЧЕБНИК`, `ДАКТИЛЬ_А`), и жест выбирается по нему.
- Для файла на жест имя файла — транслит глоссы: `uchebnik.glb`, `daktil_a.vrma`,
  `cifra_5.glb`.
- Глоссы дактиля и чисел: `ДАКТИЛЬ_А` … `ДАКТИЛЬ_Я`, `ЦИФРА_0` … `ЦИФРА_9`.
- Формат: `.glb` (работает сразу) **или** `.vrma` (нужен пакет
  `@pixiv/three-vrm-animation`). Не дублировать один жест в двух форматах.
- Длительность 0.5–2.5 с, нейтральная поза в начале и конце.

Файл с несколькими жестами импортируется командой
`python manage.py import_animations <файл>` (см. `../docs/ANIMATIONS.md`).

## Тестовые анимации

Для локальной проверки рига скрипт создаёт VRMA с десятью демонстрационными
позами:

```bash
python scripts/make_gestures_vrma.py
```

Записи для словаря готовятся из Slovo или проверяются экспертом перед
импортом. Демонстрационный VRMA помечен метаданными генератора.
